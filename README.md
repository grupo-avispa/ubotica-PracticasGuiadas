# ubotica-PracticasGuiadas
This is a resource folder for Microbótica, an Optative subject at Grado de Ingeniería Electrónica de Telecomunicación, Universidad de Málaga.

It contains practices and example projects to be used with the ESP32-S3-DevKitC-1-N16R8v board.

This folder contains:
  - Enunciados: The .pdf files containing instructions for guided practices (in Spanish)
  - Codes: the PlatformIO projects used in the guided practices
